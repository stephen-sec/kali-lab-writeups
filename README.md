## Format

Each lab follows the STAR-T incident report format:

- **Situation** — The scenario or question being investigated
- **Task** — The specific objective of the session
- **Action** — Commands run, methodology used, step-by-step approach
- **Result** — What was found, learned, or confirmed
- **Tool** — The tool used and why it was selected
